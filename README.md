# Vanya

A Telegram bot personal assistant built with Python.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Set your Telegram bot token:
```bash
export TELEGRAM_BOT_TOKEN="your-token-here"
```

3. Run the bot:
```bash
python main.py
```
